# 📊 Numerical Methods Lab Codes

This repository contains Python implementations of various **Numerical Methods algorithms** developed as part of a lab/practical coursework.

---

## 🚀 Contents

### 🔹 Root Finding Methods

* Bisection Method
* Regula Falsi Method
* Newton-Raphson Method

### 🔹 Linear Algebra Methods

* Gauss Elimination Method
* Gauss Seidel Method
* Jacobi Method

### 🔹 Interpolation Methods

* Newton Forward Interpolation
* Newton Backward Interpolation

---

## 🛠️ Technologies Used

* Python 🐍
* Jupyter Notebook (.ipynb)
* NumPy (for some implementations)

---

## 📂 How to Run

1. Clone the repository:

```bash
git clone https://github.com/avinashEmmanuel/Numerical-Methods-Lab-Codes.git
```

2. Navigate to the folder:

```bash
cd Numerical-Methods-Lab-Codes
```

3. Open notebooks using:

* Jupyter Notebook
* VS Code (recommended)

---

## 📌 Notes

* Each notebook contains:

  * Algorithm implementation
  * Example input/output
* Some methods assume:

  * Equal interval spacing (for interpolation/integration)
  * Valid mathematical conditions (e.g., convergence)
